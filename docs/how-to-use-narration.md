# How to Use Walkthrough Narration

**Voice direction:** English (United States), clear informative narrator, warm and confident, steady conversational pace, concise instructional delivery. Leave short pauses between workflow steps.

**Spoken script:**

Welcome to Contrastive Speech Analytics. First, upload the participant recording and an ideal reference. Confirm that both follow the same transcript. Start the analysis to align the speech and extract acoustic features. On the timeline, select a flaw to jump to its timestamp. Review the affected words, baseline and participant values, threshold, confidence, and explanation. Finally, use the transparent score breakdown to decide what to practice next. Demo data is shown here; production results come from the connected API.
