# data/ Directory

## Structure

```
data/
  raw/           Source WAV files (*.wav) + matching transcripts (*.txt)
  flawed/        Injected-flaw WAV files generated by src/dataset/generate.py
  labels/
    injections.csv          Ground-truth flaw labels for all flawed files
    alignments/             Cached forced-alignment JSON (keyed by SHA-256 hash)
```

## injections.csv Columns

| Column | Type | Description |
|---|---|---|
| `file` | string | Filename in `data/flawed/` |
| `source` | string | Original WAV filename from `data/raw/` |
| `flaw_type` | string | One of the `FlawType` enum values (e.g. `PACE_TOO_SLOW`) |
| `severity` | int (1–5) | Injection severity level |
| `start_sec` | float | Flaw region start in the **new** audio timeline (seconds) |
| `end_sec` | float | Flaw region end in the **new** audio timeline (seconds) |

> [!NOTE]
> `start_sec` and `end_sec` are measured in the **output** file's timeline, not the source file's. Duration-shifting flaws (slow, fast, pause insertion, filler) shift all subsequent timestamps.

## Adding Source Audio

1. Copy your WAV files to `data/raw/`.
2. Create a matching `.txt` file with the exact transcript (same stem, e.g. `speech_01.txt`).
3. Run: `python -m src.dataset.generate`
4. Validate: `python scripts/validate_labels.py`

## Notes on Filler Injection

Filler clips are currently **synthetic** (a 150 Hz sine buzz). Place real filler
recordings (uh, um, etc.) in `data/raw/fillers/*.wav` and update `_injector_filler`
in `src/dataset/generator.py` to load them instead.

## Notes on Pitch Flattening

Monotone injection uses **Parselmouth** (praat-parselmouth 0.4.7) to directly
manipulate the pitch tier via PSOLA resynthesis — the most acoustically faithful
method. No librosa-based fallback is used; Parselmouth must be installed.
